# PatchTheCVE

**[patchthecve.com](https://patchthecve.com)** is a free CVE tracker that ranks vulnerabilities by real-world risk and shows the exact fix for your system.

- Full NVD history, updated every 2 hours
- Priority from CISA KEV (exploited in the wild), EPSS and public exploits
- Fixes per distro (Ubuntu, Debian, RHEL, SUSE, Alpine, Arch, Fedora, Amazon Linux), Windows KB with offline install steps, and package ecosystems
- RSS feeds, open data, and a "check my software" tool, no sign-up

This repository holds the build and deploy workflows for the public site. Latest exploited CVEs: https://patchthecve.com/exploited.html · Feeds: https://patchthecve.com/feeds.html
